# Onest Variable

`Onest-Variable.woff2` is the lossless WOFF2 conversion of the full variable
`Onest[wght].ttf` from https://github.com/google/fonts/tree/main/ofl/onest.
It retains Latin and Cyrillic coverage and the 100–900 weight axis.

Source TTF SHA-256: `966c5c29b4755da84b6854d5c21dd4eaa2420225d0e9874de602de176d4a9f31`.
Converted with fontTools 4.60.1 and Brotli 1.1.0, using `TTFont.flavor = 'woff2'`.
The SIL Open Font License is included in `OFL.txt`.

Load only through `next/font/local` in the root layout. The MUI theme owns the
typography settings; no external font service or runtime dependency is required.
