# Главная страница

Главная использует существующие ViewerProvider, PlayerProvider и QueuePanel. Продолжение восстанавливается из текущего состояния плеера; отдельной истории позиции воспроизведения нет. Все личные запросы идут через BFF с `private, no-store`, серверные маршруты защищены SessionGuard.

- `/home/releases`: публичная страница последних 20 доступных треков, курсор по убыванию ObjectId. Порядок каталога не изменён.
- `/home/popular`: топ доступных треков по AccountListen за 7 суток. Гостевые прослушивания не входят: существующая модель хранит для них только общий счётчик, без даты. Диапазон времени индексирован; агрегация одна на блок, не на строку.
- `/home/activity`: публикации, комментарии и оценки текущих друзей без блокировок. Каждый запрос заново проверяет отношения и доступность. Источники читаются порциями по 21 записи, объединяются, выдаются по 20. Курсор продвигается и через удалённые треки; клиент может получить пустую страницу с продолжением. Повторные действия одного автора с одним треком за день сворачиваются в пределах загруженных страниц.

Лента читает исходные объекты: удалённые комментарии и треки не оставляют событий. Избранное, прослушивания и интересы друзей не публикуются и не используются для рекомендаций без настроек согласия. Публичных плейлистов в проекте нет. Список друзей не показывает выдуманное время присутствия.

Рекомендации детерминированно ранжируют последние 20 релизов по исполнителям из последних 30 записей личной истории и 30 избранных; затем предпочитают ещё не прослушанные треки. При отсутствии данных сохраняется порядок свежести. Личная недельная сводка явно ограничена последними 30 прослушиваниями; это не полный недельный отчёт. Недавние исполнители не называются любимыми без достаточной истории.

Индексы запросов объявлены в схемах и создаются HomeService при старте, поскольку глобальный autoIndex отключён. Новые зависимости и тесты не добавлялись.

Проверки: client/server typecheck, lint и production build; клиентские unit-тесты 90/90. Серверные unit-тесты: 109 успешно, 8 ошибок в media-validator из-за отсутствующего ffmpeg. Запуск Chromium для визуальной проверки блокируется отсутствующей системной libnspr4.so; реальные пользовательские сессии и воспроизведение в браузере требуют проверки в окружении с установленными браузерными зависимостями и работающим backend.
